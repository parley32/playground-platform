**Learned:** Plain `ps` shows only the current terminal and no PPID; choose columns with `-o`. `pstree` shows threads in `{braces}`. In `STAT Sl+`, `S` = sleeping, `l` = multi-threaded, `+` = foreground process group. `go run` builds a temporary binary and runs it as its own child, so the parent is `go`, and it reports `exit status N` but exits 1 itself; build to `bin/` for anything about PIDs, signals or exit codes. `exec.Command` runs no shell, so every argument is its own string. `...` passes a slice to a variadic parameter (last position, on its own); Go has no general spread. `flag.Args()` is empty until `flag.Parse()`, and parsing stops at `--` or the first non-flag argument. `Wait()` blocks, so it gets a goroutine + channel like any other blocking call.

## Plan: Phase 3 TCP server (block 2)

**Goal:** `week03/tcp-echo-server/server` speaks a small line protocol (`PING`, `ECHO`, `SET`/`GET`), drops idle clients, and shuts down cleanly on Ctrl+C.

**First action:** From `week03`, run `go run ./tcp-echo-server/server` in one terminal and `nc 127.0.0.1 8080` in another. Type a line and watch it echo, then leave it idle. Note that nothing ever disconnects you.

**Steps:**
1. Idle timeout: call `conn.SetReadDeadline(time.Now().Add(idleTimeout))` before each read; check with `nc`.
2. Protocol: split `handleConn` so a pure function `handleCommand(line string) string` handles `PING` → `PONG`, `ECHO <text>`, anything else → `ERR unknown command`.
3. Table test for `handleCommand` (including bad input), then keep the existing `net.Pipe` test passing.
4. `SET k v` / `GET k` backed by a shared map guarded by a mutex; test with several concurrent clients under `go test -race`.
5. Framing safety: reject lines over a maximum length instead of buffering forever.
6. Graceful shutdown: `signal.NotifyContext`, close the listener on `ctx.Done()`, `WaitGroup` for in-flight connections.
